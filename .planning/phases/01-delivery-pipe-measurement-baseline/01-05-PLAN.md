<objective>
Re-measure the cobolprobe recall baseline through the local vendoring path and record it, together
with the build order and the measured volumes that justify it.

Purpose: every phase from here on is judged by a recall delta. A delta is only meaningful against a
baseline measured with the same corpus, the same method, and the same grammar lineage. The
previously published figures were measured through forest v1.9.1 — a photocopy generated from an
older revision of upstream's grammar — so they are not automatically this fork's baseline. This plan
produces the number phases 2-4 are actually held to.

Output: `docs/baseline.md`.

Wave note: this plan is sequenced after plan 04 rather than beside it because both need gortex's
single uncommitted workspace file pointed at the main shim, and this plan holds it for a
twenty-minute run.
</objective>
