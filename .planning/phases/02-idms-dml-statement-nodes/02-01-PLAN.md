<assumption_delta_decision>
**Primary noun:** the grammar-alone `.cbl` `dataItems` count (`docs/baseline.md` §2 — 17,905).

**Decision: `promote`.** Phase 1 established one recall axis. Phase 2 splits it into two —
grammar-alone and `+ neutralize()` — and D-13 promotes **grammar-alone** to the primary measure,
demoting the `neutralize()` figure (32,360) to a retiring baseline whose terminal condition is
"grammar-alone >= neutralized, i.e. `neutralize()` retires".

**Rationale:** `neutralize()` already rewrites all 14 IDMS DML verbs (gortex
`cobolprobe/neutralize_test.go:24`, `reDML`), so the neutralized figure is a **ceiling this phase
climbs toward**, not a bar it clears. Leaving it primary would report a succeeding phase as a
failure — which is exactly what ROADMAP Phase 2 criterion 4 originally did before the D-16
amendment.

**Not `add-alongside`:** keeping both axes co-primary would preserve the contradiction. The
neutralized number survives only as the terminal-condition target, not as a pass/fail bar.

**Invariant test (accepted, carried in 02-06's `must_haves.truths`):** the recorded Phase 2 delta is
expressed as `(X - 17,905) / 14,455` on the grammar-alone axis and never as an absolute percentage
against the borrowed 121,457 denominator. That truth goes red the instant a later phase
reintroduces the single-axis absolute-percentage framing.
</assumption_delta_decision>
