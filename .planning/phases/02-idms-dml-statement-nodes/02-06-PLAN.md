<assumption_delta_decision>
**Primary noun:** the grammar-alone `.cbl` `dataItems` count (`docs/baseline.md` §2 — 17,905).

**Decision: `promote`.** Phase 1 established a single recall axis. Phase 2 splits it into two —
grammar-alone and `+ neutralize()` — and D-13 promotes **grammar-alone** to the primary measure,
demoting the `neutralize()` figure (32,360) to a retiring baseline whose terminal condition is
"grammar-alone >= neutralized, i.e. `neutralize()` retires".

**Rationale:** `neutralize()` already rewrites all 14 IDMS DML verbs (gortex
`cobolprobe/neutralize_test.go:24`, `reDML`), so the neutralized figure is a **ceiling this phase
climbs toward**, not a bar it clears. Leaving it primary would report a succeeding phase as a
failure — which is exactly what ROADMAP Phase 2 criterion 4 did before the D-16 amendment, since
`neutralize()` also fixes the 169 DCC files containing `EXEC CICS` and grammar-alone after
IDMS-only work will very likely land below 26.6%.

**Not `add-alongside`:** keeping both axes co-primary preserves the contradiction. The neutralized
number survives only as the terminal-condition target, never as a pass/fail bar.

**Invariant test (accepted, wired into this plan's `must_haves.truths` and Task 4's acceptance
criteria):** the recorded Phase 2 delta is expressed as `(X − 17,905) / 14,455` on the
grammar-alone axis and never as an absolute percentage against the borrowed 121,457 denominator.
That truth goes red the instant a later phase reintroduces the single-axis absolute-percentage
framing.
</assumption_delta_decision>

<flagged_assumptions>
- **"`idms_unparsed_tail` must not grow" needs a baseline to be measurable (D-15, IDMS-05).** The

  literally "growth" — which would make the gate unsatisfiable by construction, since the tail is
  designed to fire. This plan reads it the only way consistent with D-09's "count tails, then
  extend where the volume is": the census is measured at the minimal-to-edges option set, that
  becomes the within-phase baseline, and any D-09 extension must leave the count less than or equal
  to it. The Phase 2 final count then becomes Phase 3's baseline. Surfaced explicitly because it is
  an interpretation, not a restatement.

- **`.cpy` grammar-alone recall stays at 0% and that is not a Phase 2 failure.** Copybooks have no
  `IDENTIFICATION DIVISION` to anchor a parse, so the grammar yields nothing for them standalone
  while `neutralize()` reaches 93%. Structural, outside every phase in this milestone, and noted
  here so nobody reads the 0% row as a regression.

- **Recall on DCC is not purely a function of this grammar (D-15).** Endevor `-INC` covers 61% of
  estate programs and is preprocessing's problem; the `.cpy` axis is structural. Gating hard on a
  number the phase does not fully control invites redefining the number, which is why D-15 makes
  direction blocking and magnitude explained.
</flagged_assumptions>
